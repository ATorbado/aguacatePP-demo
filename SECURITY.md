# Seguridad

La edición pública funciona en modo de demostración y no debe contener
credenciales, dominios privados ni datos operativos reales.

Si encuentras un dato sensible, no lo publiques en una incidencia. Comunícalo
de forma privada al propietario del repositorio e indica solamente el archivo y
el tipo de dato. Una credencial expuesta debe revocarse aunque después se borre
del historial.
