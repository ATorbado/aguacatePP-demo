# Animales (demostración pública)

Versión ejecutable con datos ficticios. Muestra el flujo básico de un parte,
pero no conecta con servidores, correo, ubicación, cámara ni almacenamiento
privado.

## Ejecutar

```bash
flutter pub get
flutter run
```

No necesita variables de entorno, cuentas ni credenciales. El botón final solo
simula el envío y confirma que no se ha contactado con ningún servicio.
